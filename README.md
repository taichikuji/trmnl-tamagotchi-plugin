# trmnl-tamagotchi-plugin

Your nostalgic friend on TRMNL! A P1-style virtual pet with full, half and quadrant layouts for TRMNL OG and TRMNL X.

## Features

- Original P1 pixel artwork
- A seeded caretaker with attentive, inconsistent or neglectful care
- Evolution shaped by care history
- Food, joy, age and generation indicators
- Local sleep schedules and automatic rebirth
- Responsive TRMNL X landscape and portrait layouts

## Local development

Open `TRMNL/` with [TRMNLP](https://github.com/usetrmnl/trmnlp) to preview all four layouts. For selectable characters, the seeded lifecycle preview and verification commands, see the [development guide](docs/DEVELOPMENT.md).
